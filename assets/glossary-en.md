# Glossary & tier mapping — English edition

Use these consistently in `book-en/`. When a term is missing, pick the standard English term the original publisher used, and keep it identical everywhere.

## Source tiers (1:1 with the Chinese edition)

| Chinese | English |
|---|---|
| 【官方口径】 | [official] |
| 【第三方验证】 | [third-party verified] |
| 【厂商宣称】 | [vendor claim] |
| 【本书判断】 | [our judgment] |
| 【本书实测】 | [our own measurement] |
| 【存目·本轮未核到正文，不入正文】 | [listed only — full text not reachable this round, not cited in the body] |

**Qualifiers** ride inside the tier after a colon, mirroring the Chinese "•": 【官方口径·平台自报】 → `[official: platform-reported]`; 【第三方验证·预印本】 → `[third-party verified: preprint]`; 【第三方报道验证，单源，降级使用】 → `[third-party reported: single source, used with caution]`.

## House style

- Headings: `## Method 3: <imperative>` (mirrors 《## 办法 N：…》).
- Four blocks inside a method: `**What to do**` / `**How**` / `**Example**` / `**Pitfalls**`.
- Part openers keep their one-line epigraph as a blockquote.
- Keep Chinese source names as published (e.g. 虎嗅 → Huxiu, 界面新闻 → Jiemian News), adding a translation only when the publication has an official English name.
- Punctuation: use the serial comma; keep the em dash style of the original.
