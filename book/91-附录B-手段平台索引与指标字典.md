# 附录 B · 手段平台索引表与指标字典

## B.1 手段平台索引表

填写口径：**AI 增益**＝该手段用 AI 改造后的效率提升幅度；**成熟度**＝在企业实际落地中的普及程度；**合规风险**＝违规后果的量级；**成本**＝单位动作的边际成本量级。四列均为【本书判断】，依据是各章引用的公开规则与案例，读者应按自有数据校准。

### 海外侧

| 手段 | 主要平台/工具 | AI 增益 | 成熟度 | 合规风险 | 成本量级 |
|---|---|---|---|---|---|
| 答案层可见度建设（GEO/AEO） | Google AI Overviews / AI Mode、ChatGPT Search、Perplexity、Claude | 高（内容结构化与实体一致性可系统化） | 中（方法论未定，工具先行） | 低（但操纵类做法风险高） | 人力为主，工具费为中低 |
| 第三方信源建设 | 行业垂直媒体、G2/Capterra、Reddit、Wikipedia/Wikidata | 中（可辅助调研与素材整理，不能替代一手材料） | 低（多数企业仍停留在通稿） | 低 | 中（深度内容的单位成本高） |
| 信号驱动外联 | 意图数据平台 + 邮件/社交触达 | 高（信号识别与背景调研） | 中 | **高**（域名信誉、平台封号） | 低（发信边际成本趋零） |
| 邮件触达 | 自有域名 + 认证体系（SPF/DKIM/DMARC） | 高（个性化与节奏自动化） | 高 | **高**（投诉率、监管） | 低 |
| 社交平台触达 | LinkedIn 等 | 中（情报价值高、触达受限） | 中 | **高**（用户协议禁止未授权自动化） | 中 |
| AI 语音外呼 | 语音 Agent 平台 | 低（首轮筛选可用，深度对话不成立） | 低 | **极高**（TCPA，未获同意即违法） | 低（单次通话成本极低） |
| Agent 采购接入（机器客户侧） | MCP、A2A、AP2 等协议与购物助手 | 待观察（协议已动工，实际成交量小） | 低 | 中（授权与责任归属未定） | 中（接口与目录工程） |

## B.2 指标字典

每个指标给出：定义、口径、典型误用。**指标质量决定 AI 获客的上限**——AI 是吃标签的动物。

| 指标 | 定义（本书口径） | 典型误用 |
|---|---|---|
| 线索（Lead） | 留下可联系身份信息，未做资格判断 | 把表单提交量当"需求规模" |
| 营销合格线索（MQL） | 满足事先约定的画像 + 行为判据（判据须销售签字） | 放宽判据以完成季度 KPI |
| 销售接受线索（SAL） | 销售在约定时限内跟进并明确接受 | 接受率不统计，形成无人认领池 |
| 销售合格商机（SQL） | 有预算、有时间表、有决策人进场 | 用"意向强烈"这类形容词替代硬字段 |
| 赢单与首款回款 | 合同签署 + 首笔款项到账 | 把口头承诺、意向书当获客终点 |
| 可见度稳定率 | 固定问题集中，稳定提及本企业的比例（多入口、多轮次） | 用单次测试结果当结论 |
| 表述准确率 | 模型转述中，参数/价格/资质等硬事实正确的比例 | 只看"提没提到"，不看"说得对不对" |
| 被引用来源构成 | 模型引用的来源类型分布（官网/第三方/评测/社区） | 只看引用数量，不看来源性质 |
| 增量效果 | 通过受控缺席（分地区/分时段暂停）测得的因果效应 | 用自报数据或归因工具数字代替实验 |
| 触达资产健康度 | 域名投诉率、账号警告数、线路接通率、名单来源合法性 | 只看发送量，不看资产损耗 |
| 一手素材产出率 | 单位时间内新增的、别人无法复制的证据数量 | 用内容产量替代证据产量 |

## B.3 使用建议

1. 五档标签必须先与销售签"定义合同"，任何判据变更走评审；
2. 可见度稳定率与表述准确率按月记录，与表述错误清单一起进入跨部门巡检会（第 6、23 章）；
3. 增量效果每季度至少对一项投入做受控缺席实验（第 20 章）；
4. 触达资产账本每周过一遍（第 13 章），增长冲刺前先过账本。
