## 这本书在讲什么

**获客不是企业发出的动作集合，而是企业获得进入买方决策过程资格的过程。**

当买方把问题交给 AI，他得到的不是一个入口，而是一个结论。于是出现了一个对企业来说全新的局面：那个位置，花钱买不到。这本书讲清楚四件事：

- **买家已经先到了**：入口如何从"一列结果"折叠成"一个答案"，候选集如何在你不在场时完成筛选；
- **拿什么去被选中**：被引用、被机器读取、被第三方证实的机制与动作；
- **主动的那一半**：触达、外联、线索定义与 Agent 采购的真实边界；
- **证明、边界与收束**：归因与增量实验、平台依赖与对冲、组织与人机分工、失败档案。

终点线划在**完成首次交易/签约**为止（留存与 LTV 属于《AI 客户经营》）。

## 三条纪律

1. 每个数字都追到原始发布方，聚合站与工具商摘要只当线索；
2. 每条来源标注性质：【官方口径】【第三方验证】【厂商宣称】【本书判断】【本书实测】；
3. 核不到原始出处的数字，删掉不写；多家口径不一致时并列差异。

## 本书自建实测

本书不止引用别人的数据。第一卷就带上了自己的一手实测：**候选集多模型实测**——6 个真实采购问题（3 组中英对照）× 5 个模型通道 × 每题 2 次，共 51 条有效答案，方法、原始数据与缺口全部公开存档（见 `实测/`）。核心结论：候选集是**分布**而不是名单；中文与英文入口给出的是**两套几乎不相交的候选集**。
