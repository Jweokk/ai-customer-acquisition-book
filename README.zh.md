## 这本书在讲什么

**客户挑供应商的地方换了。** 他们不再只在搜索框和展会上比较——开始问 AI、让 Agent 去筛、看平台推的和别人说的。

这本书按客户实际走的那条路来写：**找到 → 选中 → 谈成 → 带走**。每一步都先讲清楚客户在这一步是怎么挑的，再给可以直接照做的办法。全书 **24 章、135 个办法**，每个办法都是同一套四块：做什么 / 怎么做 / 例子 / 别踩的坑。

- **第一篇 先看清战场**：客户到底在哪儿挑，你在不在场；
- **第二篇 AI 时代的新方法**：客户新增的几条路——AI 的回答、第一份名单、别人怎么评价、机器读不读得懂你、买家的 Agent 会不会选中你；
- **第三篇 用 AI 改造老办法**：广告、平台、渠道、内容、外联、产品、电话私域——老路都没消失，只是走法换了；
- **第四篇 别白花钱、别把地基打歪**：三套账本、依赖体检、一方数据与合规、人怎么排、红线在哪。

终点线划在**完成首次交易/签约**为止（留存与 LTV 属于《AI 客户经营》）。

## 三条纪律

1. 每个数字都追到原始发布方，聚合站与工具商摘要只当线索；
2. 每条来源标注性质，主干五档 + 括注：【官方口径】【第三方验证】【厂商宣称】【本书判断】【本书实测】，例如【官方口径·平台自报】；
3. 核不到原始出处的数字，删掉不写；多家口径不一致时并列差异。

引用是两层的：正文里每个数字句末带性质分档，读到哪一条当场就知道它有多硬；每章末尾列本章来源，就近可查；[附录 E](book/94-附录E-全书参考文献.md) 把全书来源合并去重、统一编号（314 条），供外部引用。正文不加数字上标。

## 本书自建实测

本书不止引用别人的数据。**候选集多模型实测**：6 个真实采购问题（3 组中英对照）× 5 个模型通道能力档（A–E）× 每题 2 次，共 51 条有效答案，方法、原始数据与缺口全部公开存档（见 `实测/`）。核心结论：候选集是**分布**而不是名单；中文与英文入口给出的是**两套几乎不相交的候选集**。
