# 《AI 获客》章目 v6 · 定稿（24 章 + 附录）

## 标题命名规则（这次定死）

1. **主标题必须一眼看懂"要做什么、能得到什么"**，禁止用行业术语当标题（暗漏斗 / 候选集 / 验证经济 / 机器可读 一律不许出现）。
2. **格式**：`第 N 章 动宾短句（≤12 字）：一句说明这章是"新增了什么能力"还是"把老办法优化成什么样"`。
3. 老办法章用**「从 X 到 Y」**句式，读者一眼看出改了什么。
4. 新方法章用**「让……」「怎么……」**句式，读者一眼看出新增了什么。
5. 每章正文前两句：① 这章解决什么问题 ② 你读完能拿走什么。

---

## 序 · 客户找供应商的方式变了

**说明**：一张全景图（找到 / 吸引 / 转化 / 扩大 ×「AI 新增的能力」与「AI 优化的老办法」）＋一个公式（获客结果 = 触点数量 × 相关性 × 信任度 × 转化率 ÷ 成本）＋怎么读这本书。
**篇幅**：2,000–2,500 字。
