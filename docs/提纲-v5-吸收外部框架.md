## 一、三份框架的共同点（我们该吸收的）

三份说法虽然措辞不同，指向同一件事：

**AI 时代获客 = 两条线 × 一条链路**
- 两条线：**AI 原生新方法**（AI 造出的新入口）／**AI 改造老方法**（渠道没变，工序变了）
- 一条链路：**找到 → 吸引 → 转化 → 扩大**（对应传统漏斗：认知 → 留资 → 信任 → 成交 → 裂变）

它们比我们多的三样东西：

1. **一张全景图**（读者打开书先看见地图）：4 个层次 × 2 种变化；
2. **一个公式**：获客结果 = 触点数量 × 触点相关性 × 信任度 × 转化率 ÷ 获客成本——**解释 AI 到底改了什么**（放大前两项、让信任更稀缺）；
3. **三条落地原则**：先聚焦（选 1–2 个渠道打透）、看单位经济（CAC < LTV）、护城河在信任层（AI 让产能趋同后，差异化只剩真实数据/案例/真人观点）。

这三样我建议**放进序和收尾章**，不占正文章节。

## 四、必须说明：附件里的数字基本不能用

附件框架里的这些说法，按本书的口径**一律不能进正文**（多为自媒体、软文或转引，核不到原始出处）：

| 附件里的说法 | 问题 |
|---|---|
| "AI 推荐线索转化率超 35%" | 无原始出处；且"线索转化率"未定义分母 |
| "获客成本下降 50%、线索精准度提升 70%" | 典型软文口径（该文源头是网易号自媒体，且自称引用 IDC/易观等"出版报告"，无法核验） |
| "老客户复购率可提升 40% 以上" | 无出处；且复购属《AI 客户经营》边界 |
| "CDP 让营销 ROI 提升 25%" | 无原始报告 |
| "Gartner 建议预测工具准确率至少 80%" | 需回 Gartner 原文核对 |
| "传播率提升 50%" | 无定义、无出处 |

**这些框架的价值在结构，不在数字。** 凡进正文的数字，仍按我们的规矩：追到原始发布方，核不到就删。这也是本书区别于市面上"AI 获客趋势文"的地方——那些文章十篇里有九篇在互相转抄同一批没出处的数字。
