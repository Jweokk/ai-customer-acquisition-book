## 三、缺口（这一章还差什么）

1. **中国侧广告法规原文**：《广告法》《互联网广告管理办法》里关于"广告可识别性"和 AI 生成素材的条款——目前只有《标识办法》。
2. **素材衰退（creative fatigue）的可核证据**：官方只给到 Ad Strength 的"素材多样性"建议；第三方那批百分比不可用。要么找到 Google／Meta 官方口径或学术研究，要么**正文只写机制不写数字**。
3. **三个平台官方条目的覆盖还不够**：巨量／腾讯／百度目前各只有 1–2 条帮助中心链接，要按"自动出价／自动扩量／学习期／素材预审"逐项补齐。
4. **一个可核的行业级效果数字**：找不到就不写。

## 四、这一章的办法方向（草案，等素材补齐再定稿）

1. 把"选人群"改成"给目标"——设目标转化成本，让系统找人（百度 oCPC、巨量自动出价、腾讯自动版位）
2. 让系统扩量，但得给它好种子——Asset Group Signals 是提示不是硬靶（Google 官方 API 文档原话）
3. 素材就是投放的产能——一批素材跑赛马，看系统的素材多样性评分（Ad Strength）
4. 广告也要过"AI 标识"这一关——生成素材的显式／隐式标识义务
5. 一方数据喂回去，投放才有回路——把自有名单推给广告平台再看回收
6. 别在广告里把自己说错——可识别性 + 平台审核，别把合规成本算漏
