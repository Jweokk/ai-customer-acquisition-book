## 分档使用提醒（与附录 A 口径一致）

- **【厂商宣称】**（B5 Klarna、B7 Amazon Rufus）：只能作线索，**不得当事实**；引用时须标出厂商身份与利益关系。B5 的"700 人"是**工作量换算**，不是裁员数——很多二手文章把它读成"裁了 700 人"，本书不要跟着错。
- **【第三方整理·财报电话会转引】**（B11 detailed.com/public）：数字原始出处是**公司自己的财报电话会**，detailed.com 是转引与翻译整理；正文若要写，建议标"公司财报电话会口径"，或回到公司 IR 页面二次核验。
- **【第三方报道】**（B4/B8）：官方稿更硬，但本次官方页 curl 未通过（见表末备查）；正文引用时注明"据 CNBC/CIO Dive 报道"。
- **金额类**（B2 Reddit 的 $60M/年）：官方博客只讲合作范围，**金额来自媒体**，不能写成"Google 官方确认 6000 万美元"。
