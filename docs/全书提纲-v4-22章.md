# 《AI 获客》全书提纲 v4（22 章 · 办法体）

> 写法：每章 = 目标（2–3 句）+ 5–12 个办法（每个 250–450 字：做什么 / 怎么做 / 例子 / 坑）+ 本章注意 + 本章数据来源。
> 两条主线：**第二篇 = AI 时代的新方法（AI 造出的新入口）；第三篇 = 用 AI 改造老方法（渠道没变，工序变了）**。第四篇是配套（别白花钱、别被掐死）。
> 篇幅目标：每章 3,000–5,000 字，全书约 8 万字。

---

## 序 · 为什么现在要在 AI 里获客

**概要**：一句话交代这本书教什么——**在 AI 时代，把你该拿的客户拿到手**。讲清两件事变了：买家换地方了（他直接问 AI，不再翻十页结果）；你手里的老办法需要 AI 加持才有竞争力。再交代两条主线、终点线（写到完成首次交易/签约为止）和怎么读。

**篇幅**：2,000–2,500 字。

# 第一篇 先看清战场

## 第 1 章 买家换地方了：你的客户现在怎么找供应商

**概要**：这一章不给办法，只做一件事——**让读者知道自己现在在不在场**。讲清入口变了的三个事实（问题被 AI 整段接走、结果被折叠成一个结论、点不点都不重要了），然后当场做一次入口审计。

**办法清单（5 个）**
1. 每月问 AI 25 个问题，看它怎么描述你
2. 问题分三层来问（品类 / 功能 / 带条件的场景问法）
3. 每次只记四个字段（提到没 / 位次与对错 / 引用谁 / 竞品同场）
4. 看稳定率，不看单次结果（我们实测：同题两次重合 22%–56%）
5. 分清"产品层"和"模型层"（别拿裸模型没有引用，来否定 GEO）

**素材**：现有第 1 章（压缩改造，去掉四次权力转移的历史铺陈，只留一个自然段）。

# 第二篇 AI 时代的新方法（AI 造出来的新入口）

## 第 2 章 怎么让你的产品出现在 AI 的回答里（GEO/AEO）★样板已完成

**概要**：买家问 AI"该选谁"，你要出现在它的回答里，而且不被说错。位置买不到，只能靠事实被引用。

**办法清单（10 个，已定稿）**：① 每月问 AI 25 个问题 ② 第一句就把话说完 ③ 给别人没有的数字 ④ 让全网对同一件事只有一个说法 ⑤ 读自己的服务器日志 ⑥ 别刷好评（FTC 真罚） ⑦ 别批量产模板页（Google 一夜砍 87%） ⑧ 中文市场另补三件事 ⑨ 平台把"被引用"改成"被准入"时别慌 ⑩ 找服务商之前先查他自己

**素材**：现有第 4 章（已改写完成）。

## 第 3 章 怎么挤进买方的"第一天名单"

**概要**：买家启动调研的第一天，就大致圈定了 3–5 家；后面你再去敲门，多半只是陪跑的报价工具。这一章讲怎么在那份名单里。

**办法清单（6 个）**
1. 先找出买家的第一批问题（他们一开始问什么）
2. 把你的约束条件公开成可匹配的事实（规模、参数、预算、合规）
3. 抢一个细分品类的第一（不做全能选手）
4. 让多个入口都稳定提到你（单一入口不算资产）
5. 盯"同场竞品"：看他们靠什么被提到
6. 小预算怎么打（只赢三个入口点，别撒胡椒面）

**素材**：现有第 3 章；去掉 Hauser & Wernerfelt、锚定效应等文献论证，保留 95-5、候选集实测与动作。

## 第 4 章 怎么让第三方替你说话

**概要**：AI 最信的不是你的官网，是别人怎么评价你。这一章讲怎么在"别人那里"积累真实、可核的证据。

**办法清单（6 个）**
1. 先查模型现在引用谁（找出你的"求证路径"）
2. 90 天放第一批资产（垂直媒体深度稿 / 社区真实回答 / 评测收录 / 百科条目）
3. 给第三方"能写的东西"（一手数据 + 具名案例 + 高管观点）
4. 让高管和专家出来署名说话（个人 IP 是最便宜的渠道）
5. 榜单与评测的攻守（收录错了怎么改、名次能不能买）
6. 社区经营的分寸（能参与，不能伪装）

**素材**：现有第 8 章 + 补采素材（Reddit 许可协议、评测站收录规则、创始人 IP 案例）。

## 第 5 章 怎么抢先回答"有哪些坑"

**概要**：买家第一轮问的高频问题是"有什么坑""怎么核对供应商"，而多数企业在这类问题上完全空白——解释权就交给了别人。这一章讲怎么用"有边界的坦白"把风险话题变成入口。

**办法清单（6 个）**
1. 写失败条件清单（什么情况下别选我们）
2. 写采购核对清单（帮买家审你，也顺便审竞品）
3. 主动劝退不匹配的客户（并算清总账）
4. 披露价格陷阱与隐性成本
5. 把风险内容做成销售的常规武器
6. 用三个指标看效果（使用率 / 挽回率 / 质疑频次）

**素材**：现有第 9 章；删掉 Akerlof/Spence/Eisend 的文献论证，只保留一句必要说明（"坦白是信号成本"）。

## 第 6 章 怎么让机器读懂你

**概要**：AI 和买家的 Agent 要从你的公开信息里抽取事实、核对参数、甚至直接调用。读不懂你，你就出局。

**办法清单（6 个）**
1. 做一份"唯一事实清单"（公司、产品、价格、资质、服务边界）
2. 页面结构化：首句给结论、用真表格、服务端渲染
3. 价格与配置写成可以计算的公式
4. 资质与认证做成机读版本
5. 每月巡检"被描述错"，发现就发更正
6. 别把关键信息做成图片、动画和"联系我们获取报价"

**素材**：现有第 7 章；删掉幻觉链推演与协议史。

## 第 7 章 怎么被买家的 AI 代理选中

**概要**：买家把选型甚至议价交给 AI，你面对的不再是一个人，而是他用的那套筛选系统。

**办法清单（5 个）**
1. 每周用真实采购任务测主流代理和购物助手（你在不在候选里）
2. 把产品目录和接口准备好（读不到就等于没货）
3. 价格透明（"联系销售"在代理流程里是死胡同）
4. 给自家销售 Agent 划授权边界（价格、承诺、熔断）
5. 分阶段投入：现在就做 / 有证据再加码 / 只观察

**素材**：现有第 13 章。

## 第 8 章 中文市场要多做哪几件事

**概要**：中文语料是另一套地形——公众号和平台内的内容大多抓不到，AI 能读到的中文内容少得多。这一章是中文业务的实操清单。

**办法清单（5 个）**
1. 把事实从墙内搬到公开网页（官网知识库、行业媒体、可索引平台）
2. 把条目资产弄对（百科、目录、工商信息一致）
3. 经营平台内的"前答案层"（小红书、抖音：标题即问题、首段即结论）
4. 双语文案分别写，不做翻译
5. 守合规：AI 内容标识办法（2025-09-01 起施行）

**素材**：现有第 5 章 + 第 4 章办法 8。

# 第三篇 用 AI 改造老方法（渠道没变，工序变了）

## 第 9 章 怎么让外联从"发得多"变成"发得准"

**概要**：外联还在用，但收件侧和监管同时收紧了。这一章讲怎么用 AI 提效，同时别把域名和账号打掉。

**办法清单（5 个）**
1. 信号驱动名单（招聘、融资、技术栈、高管变动）
2. AI 做背景调研和初稿，人写前三句
3. 发件域名的纪律（投诉率目标 0.1%、底线 0.3%）
4. 多渠道协同（同一份理解，不是同一条消息群发）
5. 建一本触达资产账本（域名 / 账号 / 线路 / 名单）

**素材**：现有第 10 章。

## 第 10 章 电话和私域还能不能用，怎么用

**概要**：AI 外呼是这一年最容易被忽悠的品类。这一章说清哪些红线绝对不能碰、哪些场景值得用。

**办法清单（5 个）**
1. AI 只做拨打前的情报与预约，不做陌生开发
2. 事先同意是硬前提（美国 FCC 裁决：AI 语音同样受约束）
3. 企业微信走官方能力，别碰外挂
4. 三类封号（邮件 / 账号 / 主体）与备用方案
5. 频次与话术纪律

**素材**：现有第 11 章。

## 第 11 章 怎么投广告：让 AI 帮你找人，别让它替你乱花钱 ★新章

**概要**：广告是多数公司获客预算里最大的一项，而 AI 把它从"选人群、调出价"改成了"给目标、看回传"。这一章讲怎么不被算法带着跑。

**办法清单（6 个）**
1. 先定义"什么算好客户"，再谈回传（目标设错，系统就学会找错人）
2. 目标函数怎么设：别把"表单提交"当成功
3. 素材批量生成，但要做出差异（AI 让创意成本趋零，同质化同时发生）
4. AI 答案里的广告位值不值（AI 概览广告、ChatGPT / Perplexity 商业化）
5. 广告与自然入口的配比（买位置和争引用是两件事）
6. 每周只看三件事：投诉、线索质量、单位成本

**素材**：需补采。备选线索：素材库里的 AI 广告与自动投放条目；需核 Google Ads / Meta / 巨量引擎官方文档、AI 概览广告公告、AI 素材政策。

## 第 12 章 怎么用 AI 在平台里获客 ★新章

**概要**：很多生意的客户不是"在开放网络被找到"，而是"在某个平台里被推出来"。平台内的 AI 助手正在变成新的筛选层。

**办法清单（5 个）**
1. 站内搜索：把标题、属性、价格、库存写对
2. 让平台的 AI 助手能读懂你的商品与服务信息
3. 目录与评测站收录（与第 4 章呼应，讲执行细节）
4. 平台自营挤压怎么办（自营与广告位对第三方的影响）
5. 多平台上架，事实口径统一

**素材**：需补采。备选线索：素材库已有 ASO、电商 AI 购物助手、平台治理条目；需核应用商店与电商平台官方规则。

## 第 13 章 怎么让别人替你卖 ★新章

**概要**：B2B 里渠道与集成商常常贡献一半新客；软件生态里"上架"本身就是获客。AI 时代多了新形态：进入 AI 平台的服务商目录与认证清单。

**办法清单（5 个）**
1. 找到"客户和你是同一批人"的伙伴
2. 渠道激励与赋能（AI 生成培训与素材，让伙伴卖得动）
3. 进入生态目录与认证（含 AI 平台的服务商清单）
4. 与互补品共建方案与接口（联合方案、联合报告）
5. 渠道冲突与归属规则

**素材**：需补采。备选线索：素材库里的渠道/联盟/生态条目；需核主流平台的伙伴目录与认证要求。

## 第 14 章 怎么让产品自己拉客 ★新章

**概要**：不做人的动作，靠产品把陌生人变成线索——获客成本最低的一种方式，也是 AI 时代最被低估的一种。

**办法清单（5 个）**
1. 免费额度与试用怎么设计（给多少、给多久、给谁）
2. 自助注册与沙盒（把"联系销售"这道墙拆掉）
3. 免费小工具与开放接口当入口（能被调用就是被获客）
4. 试用转付费的触发点（谁在什么时刻转化）
5. 用 AI 给每个访客定制一份演示/落地页

**素材**：需补采。备选线索：素材库里的 PLG / freemium / API 生态条目；需核试用转化基准与中文案例。

## 第 15 章 怎么让人愿意替你传 ★新章

**概要**：老客户和用户带来的新客户，是成本最低、信任度最高的一条路；AI 让它变得可自动化，同时监管开始盯假推荐。

**办法清单（5 个）**
1. 找对人：谁最可能推荐你（识别信号）
2. 挑时机：成交后、问题解决后、续费前后
3. 给由头：权益、署名、共创，别只给红包
4. 让分享变容易（一键分享、模板、AI 生成素材）
5. 别买假推荐（FTC 规则与平台治理）

**素材**：需补采。备选线索：素材库里的推荐/口碑/裂变条目；需核 FTC 规则对激励推荐的边界、中文"老带新"案例。

## 第 16 章 怎么用 AI 管线索和商机

**概要**：AI 会吃标签。标签定义错，AI 不是修正错误，而是千倍放大错误。

**办法清单（5 个）**
1. 五档标签写"定义合同"（销售签字，改判据走评审）
2. 别再放宽 MQL（放宽就是给死亡螺旋加油）
3. 账户级信号聚合（买单的不是一个人，是一屋子人）
4. 三张例会报表（档间转化 / 定义漂移 / 模型校准）
5. 每月抽样审计错档率

**素材**：现有第 12 章。

## 第 17 章 怎么用 AI 做内容，又做出别人抄不走的

**概要**：AI 让内容产能爆炸，同质内容瞬间贬值；值钱的是别人没有的一手材料。

**办法清单（5 个）**
1. 一手数据三个来源（自有数据、原始调研、实测与现场记录）
2. 案例库四要件（具名、基线、结果、可复核）
3. 采掘日历（成交后 48 小时 / 每季 / 每半年）
4. 把内容 KPI 换成证据 KPI
5. 伪一手数据的坑（样本只留好看客户、时间窗裁剪）

**素材**：现有第 6 章。

## 第 18 章 怎么让 AI 替销售干活、怎么先一步找到客户

**概要**：销售的四个环节里，哪些能交给 AI，哪些必须人做；以及怎么在客户主动找你之前先动手。

**办法清单（7 个）**
1. 四段工序分工（研究 / 找人 / 写信 / 跟进，各由谁做）
2. 三条硬规则（AI 不得未经核实发首触、价格与承诺人工发、客户负面情绪立即转人工）
3. 采购 AI SDR 的尽调问题单（六个问题）
4. "可回退"判据（什么事能交给机器）
5. 意图信号从哪来（招聘、融资、技术栈、合规罚单）
6. AI 背景简报模板（一页纸）
7. 账户优先级打分（谁在升温，谁该今天打）

**素材**：现有第 11 章（SDR 部分）+ 第 16 章（人机分工）+ 第 2 章（暗漏斗与信号）。

# 第四篇 别白花钱、别被掐死

## 第 19 章 怎么知道 AI 获客到底有没有用

**概要**：AI 入口让归因大面积失效；这一章给一套能跟老板和财务交代的算法。

**办法清单（5 个）**
1. 三套账本各回答什么问题（归因 / 自报 / 可见度）
2. 自报调研怎么问（别问"你从哪知道我们"）
3. 建可见度基线
4. 停投实验：地理对照 / 时段开关 / 剂量阶梯
5. 预算三桶与去留判定规则

**素材**：现有第 14 章。

## 第 20 章 别把命押在一个入口

**概要**：平台随时改规则。这一章讲怎么在坏消息到来那天还活着。

**办法清单（5 个）**
1. 依赖度体检 12 问（给自己打分）
2. 对冲四件套（资产 / 渠道 / 关系 / 协议）
3. 渠道风险保费（从最大渠道提 5%–10% 投自有资产）
4. 门户、搜索、推荐流三次依赖的教训
5. 资源不够时怎么对冲（靠规则，不靠钱）

**素材**：现有第 15 章。

## 第 21 章 谁来干、花多少钱

**概要**：落地瓶颈几乎不在模型，而在组织和钱怎么分。

**办法清单（5 个）**
1. 三档最小配置（1–2 人 / 5–15 人 / 50 人以上）
2. 一季只动一个杠杆（顺序：事实清单 → 入口审计 → 定义合同 → 触达 SOP → 度量例会）
3. 预算从买流量转向买资产（数据 / 知识库 / 工具 / 人）
4. 招聘与考核换轨（从"做过什么渠道"到"能不能证伪、有没有事实纪律"）
5. AI 使用边界一页纸（六条）

**素材**：现有第 16 章。

## 第 22 章 别踩这些线

**概要**：六份失败档案 + 12 问自查。都是真实发生过的、有代价的事。

**办法清单（4 个）**
1. 六份失败档案（伪背书、过度个性化、签约即错配、工具闲置、标签错位、合规翻车）
2. 12 问自查清单（给自己打分）
3. 三条原则（反制必到 / 放大器没有方向 / 闭环先于规模）
4. 最常见的失败：先自动化了一个原本就不成立的漏斗

**素材**：现有第 17 章。
