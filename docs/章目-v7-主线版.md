## 一、主线：一句话 + 四步

**一句话**（序的第一句，也是全书唯一需要被背下来的话）：

> 客户现在不只在搜索框和展会上挑供应商了——他们开始问 AI、让 Agent 去筛、看平台推的和别人说的。这本书就是教你在这几个新地方，还有那些老地方，怎么把客户拿到手。

**四步坐标**（读者用它找自己该读哪儿）：

| 步 | 客户在这一步做什么 | 你要做的事 |
|---|---|---|
| 一 · 找到 | 他第一次听说"有你这家" | 让他能碰到你：AI 的回答里、平台里、被推的信息流里、你发出去的消息里 |
| 二 · 选中 | 他开始比较，圈出一份短名单 | 让他愿意把你留在名单上：别人怎么评价你、风险你怎么答、机器读不读得懂你 |
| 三 · 谈成 | 他愿意聊了 | 把意向接住、谈成签约 |
| 四 · 带走 | 他成了客户 | 让他把下一个客户带过来 |

**本书终点线**：写到"第一次成交／签约"为止。之后的留存、复购、客户成功、交叉销售增购属于《AI 客户经营》，本书不碰。

## 二、主线可见性规则（同一句话在四个位置重复）

| 位置 | 写什么 |
|---|---|
| **序** | 上面那句话 + 四步坐标 + 读者定位表 + 那个公式 + 怎么读（上手顺序） |
| **每篇扉页** | 一句过渡，见下文四篇的篇句 |
| **每章开场第二句** | 固定句式：**"客户在这一步是这样挑的：___。所以这章给你 N 个办法：___。"** |
| **结语** | 回扣那句话 + 结语三原则（先聚焦／看单位经济／护城河在信任层） |

> 读者读三章就会形成肌肉记忆——"有逻辑"的手感就是这么来的。罗列感的病根不是章多，是读者不知道自己在整条线上的哪一格。

## 四、序 · 客户找供应商的方式变了（2,000–2,500 字）

内容顺序：

1. **主线那一句**（客户换地方挑供应商了）；
2. **读者定位表**（上面那张）；
3. **那个公式**（解释 AI 到底改了哪一项）：获客结果 = 触点数量 × 相关性 × 信任度 × 转化率 ÷ 成本——AI 把前两项变得便宜，把第三项变得更稀缺；
4. **怎么读**（上手顺序）：先用 AI 把老办法做快做准 → 再让 Agent 串起来 → 最后布局新入口；赶时间的读者按定位表跳着读；
5. **终点线**：本书写到签约为止，留存与客户经营在另一本。

### 结语（新增位，约 1,000 字）

回扣主线那一句，然后落乙的三条原则：

1. **先聚焦**——选 1–2 个入口打透，不要 24 个办法都浅尝；
2. **看单位经济**——AI 降的是成本，验证的还是 CAC < LTV；
3. **护城河在信任层**——AI 让所有人的产能都差不多之后，剩下的差别只有真实数据、真实案例和真人观点。

> 收口一句（大白话版）：客户挑供应商的地方变了，值钱的东西也跟着变了——过去值钱的是"你能做出来"，现在更值钱的是"别人愿意承认你"。
